## Study Notes

Use `def` to define a reusable operation. Parameters are names in the definition and arguments are supplied when calling it. `return` passes a value back to the caller. Keep working values local and pass inputs explicitly. Use built-ins such as `type`, `min`, `max`, and `sorted`, and import standard-library modules when they already solve the problem. For example, `statistics.mean` computes the mean of sample observations.

## Key Takeaways

- Give functions one clear responsibility and use meaningful names.
- Return results so callers can test or reuse them.
- Use clear formatting and explain non-obvious decisions in comments.
