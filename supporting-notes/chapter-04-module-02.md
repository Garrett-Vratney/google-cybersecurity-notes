## Study Notes

The kernel manages processes, memory, devices, and access to hardware. The shell interprets commands and launches programs. Distributions combine the Linux kernel with tools, package formats, repositories, and defaults. Debian-derived systems commonly use APT and `.deb` packages. Red Hat-derived systems use RPM packages and typically DNF. Programs read standard input and write normal results and diagnostics to separate standard streams.

## Key Takeaways

- Choose a distribution and package tooling that fit the environment.
- Distinguish shell errors from normal command output when troubleshooting.
- Use Linux to review logs, analyze captures, and inspect permissions.
