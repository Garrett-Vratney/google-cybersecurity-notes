## Study Notes

The operating system manages resources including CPU time, memory, storage, and device access. Applications request those resources through operating system interfaces. Firmware initializes hardware and starts the boot process. Virtual machines use virtualized hardware to run separate guest operating systems on a shared host. A GUI supports visual navigation, while a CLI supports repeatable commands and scripting.

## Key Takeaways

- Identify the OS, firmware, and application layers when troubleshooting.
- Track legacy systems and plan replacement or compensating controls.
- Use isolated VMs for repeatable configuration and recovery practice.
