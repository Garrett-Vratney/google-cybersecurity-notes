## Study Notes

Technical, operational, and managerial controls address different risks. Data owners set handling expectations and custodians implement them throughout the data lifecycle. Encryption protects confidentiality, while hashes can verify integrity. Use salted, purpose-built password hashing for password storage. PKI binds public keys to identities through certificates. Authentication verifies identity, authorization checks permissions, and accounting records activity. OAuth delegates authorization and OpenID Connect adds authentication.

## Key Takeaways

- Review dormant accounts, privilege changes, and service-account access.
- Pair SSO with MFA and monitor the identity provider and active sessions.
- Use role-based access and separation of duties for privileged workflows.
