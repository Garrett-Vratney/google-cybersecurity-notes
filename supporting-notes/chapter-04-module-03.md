## Topics Covered

- Filesystem navigation and search
- File inspection, pipes, and redirection
- User, group, and other permissions
- Ownership and privilege management

## Study Notes

Use `pwd`, `ls`, and `cd` to orient yourself. Inspect files with `less`, `head`, or `tail`. Use `grep` to search file contents and `find` for filesystem criteria. Pipes pass standard output to another command, while `>` replaces file contents and `>>` appends. Use `ls -l` to review access and `chmod` or `chown` to manage permissions or ownership when authorized. `sudo` runs commands with privileges permitted by policy.

## Key Takeaways

- Check ownership and permissions before changing access.
- Prefer the minimum privilege required for administrative commands.
- Verify the destination before redirecting output or moving a file.
