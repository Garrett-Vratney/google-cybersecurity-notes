# Google Cybersecurity Course 1 Module 4

##  Cybersecurity tools and programming languages

---

## SIEM (Security Information and Event Management)

### Definition
- An application that collects and analyzes log data to monitor critical activites in an organization

---

## Playbook

### Definition
- A manuel that provides details about any operational action

---

## Network Protocol Analyzer

### Definition
- A tool designed to capture and analyze data within a network

---

## SQL (Structured Query Language)

### Definition
- A programming language used to create, interact with, and collect information from a database.

---

## Python

### Definition
- Used to perform tasks that are repetitive and time consuming, which require a high level of detail and accuracy.

---

## Key takeaways
- SIEM tools help security analysts collect and analyze log data to monitor organizational activity
- Playbooks provide standardized procedures for handling operational and security-related actions
- Network protocol analyzers help capture and inspect network traffic
- SQL is used to interact with and manage databases
- Python is commonly used in cybersecurity automation and scripting tasks
