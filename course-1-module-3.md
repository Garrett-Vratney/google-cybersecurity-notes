## Purpose of Security Frameworks in Cybersecurity

---

## Four Core Components of Security Frameworks

### 1. Identifying and documenting security goals

#### Example
- A security analyst may be tasked with analyzing and documenting whether their organizations is out of compliance with a current federal or international policy

---

### 2. Setting guidelines to achieve security goals

#### Example
-  Your organization may need to develop new policies to align with guidelines

---

### 3. Implementing strong security processes

#### Example
- A security analyst working with a social media company may need to implement the new guideline security processes.

### 4. Monitoring and communicating

### Example
- Reporting and monitoring issues to security officers

---

### Definition
- Frameworks allow analysts to work alongside members of a security team to document, implement, and use the policies and procedures that have been created.

---

## Cia Triad

### Definition
- Foundational model that helps organizations consider risks when setting up systems and security policy

### Confidentiality

### Definition
- Only authorized users can access specified assets and data.

### Integrity

#### Definition
- Data is correct, authentic, reliable.

### Availability

#### Definition
- Data is accessible to those who are authorized to access it

---

## NIST CSF

### Definition
- A voluntary framework that consists of standards, guidelines and best practices to manage cybersecurity risks.

---

## Key Takeaways

- Security frameworks help organizations standardize cybersecurity practices
- The CIA Triad is foundational to information security
- Security analysts help implement and monitor organizational security policies
- NIST CSF provides guidelines and best practices for managing cybersecurity risks
