# Google Cybersecurity Course 1 Module 2

## Intro to the Eight CISSP Security Domains

## Concepts Covered
- CISSP Security Domains

These eight domains represent different aspects of cybersecurity.

---

## Security and Risk Management

### Definition
- Defining security goals and objectives
- Risk mitigation
- Compliance
- Business continuity
- Legal considerations

### Example
- Analysts may need to update company policy if federal policy changes

---

## Asset Security

### Definition
- Securing digital and physical assets
- Storage and maintenance of sensitive data
- Proper destruction of data

### Example
- Analysts may ensure secure destruction of sensitive data

---

## Security Architecture and Engineering

### Definition
- Optimizing data security
- Ensuring effective systems, tools, and operations

### Example
- Analysts may be tasked to configure and set up a firewall

---

## Communication and Network Security

### Definition
- Managing and securing physical networks
- Managing and securing wireless communications
- Ensuring secure and safe communication over the network

### Example
- Analysts may be tasked to analyze user behavior in their organization, ensuring communication is secure by developing and enforcing new policy

---

## Identity and Acess Management

### Definition
- Keeping data secured by ensuring established policies are followed
- Control and manage physical access, like office spaces, and logical access like applications

### Example
- An analysts may be tasked with setting up employees keycards to access the office

---

## Security Assessment and Testing

### Definition
- Conducting Security Control testing,
- Collecting and analyzing data
- Conducting security audits to monitor for risks, threats, and vulnerabilities

### Example
- Analysts may need to audit permissions to make sure employees have certain access to information

---

## Security Operations

### Definition
- Conducting investigations
- Implementing preventive measures

### Example
- Analysts in security operations may follow established procedures to investigate and mitigate detected threats.

--- 

## Software Development Security

### Definition
- Uses secure coding practices
- Create secure applications and systems

### Example
- An analyst working with software development teams to ensure following and advise proper security guidelines

--- 

## Key takeaways
- CISSP Security domains help formalize what different aspects of cybersecurity aim to achieve and do
- Each domain may have some overlap but still has it's own specific goal
- Security Domains still all follow similar security frameworks and procedures.
