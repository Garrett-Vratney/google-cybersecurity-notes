# Security Frameworks

## Definition
Guidelines used for building plans to help mitigate risk and threats to data and privacy


### Key Concept 1
Frameworks are used to create plans to address security risks, threats, and vulnerabilities, controls are used to reduce specific security risks.

# Security Controls

## Definition
Are safegaurds designed to reduce specific security risks

## Three common types of controls

### Encryption
- The process of converting data from a readable format to an encoded format, typically involving converting data from plain text to ciphertext

### Authentication
- The process of verifiyng who someone or something is

### Authorization
- The process of granting access to specific resources within a system

# Key concept 2
Controls are used alongside frameworks to reduce the possiblity and impact of a security threat, risk or vulnerabiltiy, the main types of controls
- physical controls: gates, locks, security cameras
- technical controls: firewalls, antivirus software, MFA
- Administrative controls: seperation of duties, authorization, and asset classfication

# NIST Cybersecurity Framework (CSF)

## Definition
- A voluntary framework which consists of standards, guidelines and best practices to manage cybersecurity risk.

### Areas of focus
- The security controls from the NIST CSF work hand in hand with the CIA triad principles for systems
- There are six main functions in the NIST CSF, these core functions help organizations manage risks, implement strategies, and learn from prior mistakes.

--- 

### Govern Function

#### Definition
This function emphasizes the importance of strong cybersecurity governance across all structures and processes of the organization. Establishing and maintaing the structure and processes needed to be effectively managing cybersecurity risk.

#### Areas of focus
- Setting clear objectives
- Ensuring leadership commitment
- Developing and implementing a comprehensive risk management strategy
- Continously improving cybersecurity performance

### Identify Function

#### Definition
The management of cybersecurity risk and its effect on an organizations people and assets.

#### Example
You may be asked to monitor systems and devices in organization's internal network to identify potential security issues.

### Protect Function

#### Definition
The strategy used to help protect an organization through the implementation of policies, procedures, training, and tools that help mitigate cybersecurity threats

#### Example
As an analyst you may be asked to review a new security tools set up to make sure its flagging low, medium, or high risk, then alerting the security team about any potential threats or incidents

### Respond Function

#### Definition
Making sure that the proper procedures are used to contain, neutralize, and analyze security incidents, and implement improvements to the security process.

#### Example
As an analyst you may be working with the team to collect and organize data to document an incident and suggest improvements to prevent the incident.

### Recover Function

#### Definition
The process of returning affected systems back to normal operation

#### Example
As an analyst you may be tasked with your team to restore systems, data and assets such as sensitive financial files that have been affected by a breach

# OWASP - Open Web Applications Security Project

# OWASP Security Principle
- Minimize attack surface area, otherwise known as limiting the vulnerabilities a threat actor could exploit
- Principle of least privledge, least amount of access required
- Defense in depth, organizations should be ready, multiple security controls which reduce risk
- Seperation of duties, no one should be able to have access to all systems
- Keeping security simple, allowing for more manageable systems
- Fix security issues correclty, correctly identifiying vulnerabilities properly and thoroughly

## Additional security principles
- Establish secure defaults, which means the optimal security state of an application is also the default state for users
- Fail securely, when a control stops or fails it should do so by defaulting to its most secure option
- Dont trust services, third party partners should not be explicity trusted
- Avoid security by obscurity, utilizing other security controls and measures to keep an organization safe.

# Security Audit

## Definition
A review of an organizations security controls, policies, and procedures against a set of expectations

## Internal Security Audits
- Used to help imrpove an organizations security posture and maintain compliance with regulations

## Common elements of internal audits
- Establishing scope and goals
- Conducting a risk assesment of the organizations assets
- Completeing a controls assesment
- Assesing compliance
- Communicating results

---

# Internal Audits in depth

## Establishing the scope and goals
- Identifying policies, people, and procedures which might affect an organizations security posture, goals are outlined of the organizations security objectives.

## Conducting a risk assesment
- Focused on identifying potential threats, risks, and vulnerabilities. Helping organizations consider what security measures should be implemented and monitored to ensure the safety of assets.

## Completing a controls assesment
- Involves closely reviewing existing assets, then evaluating the potential risks to those assets, ensuring that internal controls and processes are effective.

## Assessing compliance
- Organization must adhere to regulations and standards which they fall under

## Communicating results
- Summarizing the scope and goals, listing existing risks, note how quickly those risks need to be addressed, identifiying compliance regulations, and providing recommendations for improving the security posture of the organization.
